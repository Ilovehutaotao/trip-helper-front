- **容器宽度**: 固定 996px

- **栅格系统**: 内部使用 CSS Grid 组织表单项

## 栅格布局详解

```
┌─────────────────────────────────────────┐
│  城市 1 *              │ 停留天数       │
│  [文本输入 646px]      │ [旋转输入]     │
```

**Grid 容器**: 914.4px × 94px

- 第一行: 城市 + 停留天数 (2 列)
- 第二行: 添加城市按钮 (1 列，跨越)
- 第三行: 出发日期 + 旅行天数 (2 列)

#### Step 02 - 偏好设置
```
┌─────────────────────────────────────────┐
│ 交通方式 *            │ 住宿风格 *     │
│ [下拉 451.2px]        │ [下拉 451.2px] │

│ [□ 购物]     [□ 艺术]     [□ 休闲]    │
└─────────────────────────────────────────┘
```

**Grid 容器**: 914.4px × 84px
- 第一行: 2 列 (交通 + 住宿，各 451.2px)
- 第二行: 兴趣多选 (6 个复选框网格)

#### Step 03 - 特殊需求
```
┌─────────────────────────────────────────┐
│ 特殊需求                               │
│ ┌─────────────────────────────────────┐ │
│ │ 告诉我你的特殊需求，比如...          │ │
```

**容器**: 914.4px × 116.15px
- 单列布局
- 文本域占满宽度

## 断点假设（基于当前设计）

根据观测到的尺寸，推断的响应式断点：

```
Desktop XL:  ≥ 1200px  → 996px 容器可能变宽
Desktop:     996-1200px → 当前设计 (914.4px 表单)
Tablet:      768-996px  → 推测需要调整
Mobile:      < 768px    → 推测需要重排
```

**需要验证的点：**
- 小于 996px 宽度时的行为
- 平板设备 (768px) 的栅格排列
- 手机设备 (<480px) 的单列布局

## 可见性与隐藏策略

### 当前页面上的隐藏元素
- **日期选择器**: 通常为隐藏状态，点击时展开
- **下拉菜单**: 默认隐藏，选中时展开

### 推测的响应式隐藏
| 设备 | 可能隐藏元素 | 理由 |
|------|------------|------|
| 移动端 | GitHub 链接 | 链接可能不需要在移动端显示 |
| 移动端 | 配置按钮 | 可能合并到汉堡菜单 |
| 移动端 | 装饰云雾图 | 节省带宽 |
| 小屏幕 | 下拉框并排 | 改为上下排列 |

## 滚动与溢出处理

### 垂直滚动
- 页面内容超过视口高度，支持纵向滚动
- 导航栏位置：通常固定或相对定位（待验证）

### 水平溢出
- 在 996px 以下的视口可能出现横向溢出
- 表单容器 (914.4px) 可能需要水平滚动或缩放

### 内容流向

## 性能考量

### 渲染优化
- 栅格布局可使用 CSS Grid 原生性能优化
- 固定宽度容器便于计算和预测布局
- 线性垂直流减少重排次数

### 响应式优化建议
- 使用 CSS Media Queries 在断点处调整
- 考虑使用 CSS Grid 的 `auto-fit` / `auto-fill`
- 移动端可考虑使用 Flexbox 简化布局
