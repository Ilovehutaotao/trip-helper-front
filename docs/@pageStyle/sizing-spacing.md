## 间距比例体系

根据观察到的数值，页面采用的间距体系：

```
基础单位估算: 4px 或 2px

主要间距:
├─ 超小 (XS):  4-6px   (按钮内边距、微调)
├─ 小 (S):     8px     (表单项间距)
├─ 中 (M):     12px    (容器内边距、圆角)
├─ 大 (L):     18-20px (卡片内边距)
├─ 特大 (XL):  30px    (标题间距)
└─ 超大 (XXL): 70px+   (区域分隔)
```
