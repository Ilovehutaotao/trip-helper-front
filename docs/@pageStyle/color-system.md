## 色彩对比度分析

### 深色背景下的文字对比
- **标题 (白色 #FFFFFF) on 深蓝灰**: 极高对比度 ✓
- **副标题 (浅蓝 rgba(224,233,242,0.78)) on 深蓝灰**: 中等对比度 ⚠ (需确认可读性)
- **普通文本 (浅蓝白) on 深蓝灰**: 高对比度 ✓
- **表单标签 (浅蓝白 rgba(240,246,252,0.94)) on 深蓝灰**: 高对比度 ✓

### 强调色使用
- 橙色 (245, 89, 61) 在深蓝背景上对比度高 ✓
- 蓝色 (22, 119, 255) 作为链接色对比度充分 ✓

## 色彩层级

```
1. 背景层
   └─ 页面背景 (深蓝灰主背景)
   
2. 容器层
   ├─ 输入框背景 rgba(14, 27, 38, 0.66) (比页面暗一点)
   └─ 卡片背景 rgba(255, 255, 255, 0.04) (微妙浅色)
   
3. 文字层
   ├─ 主标题 白色 (最亮)
   ├─ 副标题 浅蓝 (次亮)
   ├─ 正文 浅蓝白 (常规)
   └─ 辅助文本 浅蓝 + 降低透明度 (最暗)
   
4. 交互层 (强调色)
   ├─ 主操作 橙色 rgb(245, 89, 61) (高显眼度)
   ├─ 次操作 蓝色 rgb(22, 119, 255) (中显眼度)
   └─ 标签 棕橙色 rgba(215, 110, 66, 0.85) (低显眼度)
```

## 设计意图

整个页面采用**深色模式 (Dark Mode)** 设计：
- **背景**: 深蓝灰，给人专业、沉静的感觉
- **文字**: 浅蓝白，确保足够的可读性
- **强调**: 暖色橙色，为冷色调的页面增加活力
- **层次**: 通过透明度和亮度变化实现视觉层级

这种配色适合**旅行规划类应用**，既专业又吸引用户的旅行热情。
